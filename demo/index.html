What Dendron Does

Six modules. One pipeline. Zero server.

Dendron's architecture is organized into six discrete modules, each with a single responsibility and a clean interface boundary.

Dendron is tracking your behavior right now. Scroll down, read the sections, and watch a Smart Card appear in the bottom-right corner when your intent score reaches the threshold.
📡
Tracker Module
Captures scroll depth, section visibility, reading time, cursor position, clicks, and DOM mutations using only 6 passive event listeners. All computation runs off-main-thread in a Web Worker.
🧠
Context Engine
Scores visitor intent 0–100 across three weighted dimensions: Engagement Depth (0.4×), Interaction Focus (0.35×), and Navigation Pattern (0.25×). Fires triggers when composite score > threshold.
🔢
Micro-Embeddings
Generates compact vector representations of behavioral patterns using a quantized transformer model (<25MB). Loaded lazily on first trigger. All vectors stored in IndexedDB, never transmitted.
📝
Prompt Builder
Wraps behavioral context in versioned, immutable prompt templates. Works with any LLM provider: Groq, OpenAI, Anthropic. The developer provides the LLM transport via an onQuery callback.
🎴
Card Renderer
Parses LLM responses and renders Smart Cards inside a closed Shadow DOM. Five card types: Greeting, Feature, Pricing, Engagement, Comparison. Zero CSS leakage to/from host page.
🤖
WebMCP Plugin
Optional. Auto-registers navigator.modelContext tools from the DOM, making the site discoverable by agentic browsers like Perplexity Comet and ChatGPT Atlas. Silently no-ops if WebMCP unavailable.
System Architecture

A strict unidirectional pipeline

Data flows from DOM events → Worker → Context → Prompt → Developer's backend → Rendered card. At no point does data leave the browser through Dendron's own code.

Developer Experience

One callback. Infinite intelligence.

Install via NPM or CDN. The only required parameter is onQuery — your backend's LLM transport function.

// Install: npm install @dendron-sdk/core import { Dendron } from '@dendron-sdk/core'; Dendron.init({ // REQUIRED: Route to your backend — Dendron never sees your API key onQuery: async (payload) => { const res = await fetch('/api/ai-proxy', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(payload) }); return res.json(); // Must return a SmartCard JSON object } });
Dendron.init({ onQuery: async (payload) => { /* your backend */ }, tracking: { scrollDebounce: 200, // ms cursorDebounce: 300, // ms readingInterval: 1000, // ms mutationFlushInterval: 500, // ms }, intent: { triggerThreshold: 55, // 0-100, when to fire Smart Card cooldownSeconds: 30, // seconds between triggers maxCardsPerSession: 5, // prevent fatigue }, storage: { maxStorageMB: 25, // IndexedDB cap embeddingTTLDays: 7, // embedding entry lifetime cleanupIntervalMinutes: 5, // eviction sweep interval }, ui: { position: 'bottom-right', // or 'bottom-left' theme: 'auto', // 'light' | 'dark' | 'auto' branding: true, // 'Powered by Dendron' footer zIndex: 999999, // widget z-index }, systemContext: 'Acme is a developer platform for edge deployments...', webMCP: false, // enable agent-readiness layer debug: false, // shows devtools overlay }); // Subscribe to events Dendron.on('trigger', (payload) => { analytics.track('dendron_trigger', { score: payload.trigger.score }); }); Dendron.on('card:action', (action) => { router.push(action.href); });
// app/layout.tsx (Next.js App Router) 'use client'; import { useEffect } from 'react'; import { Dendron } from '@dendron-sdk/core'; export default function RootLayout({ children }) { useEffect(() => { // Only runs on client — SSR safe Dendron.init({ onQuery: async (payload) => { const res = await fetch('/api/dendron', { method: 'POST', body: JSON.stringify(payload), }); return res.json(); }, systemContext: process.env.NEXT_PUBLIC_DENDRON_CONTEXT, }); return () => Dendron.destroy(); }, []); return <>{children}</>; }
// App.vue <script setup> import { onMounted, onUnmounted } from 'vue' import { Dendron } from '@dendron-sdk/core' onMounted(() => { Dendron.init({ onQuery: async (payload) => { const { data } = await $fetch('/api/dendron', { method: 'POST', body: payload, }) return data } }) }) onUnmounted(() => Dendron.destroy()) </script>

Security Model

Security is the architecture

Every design decision prioritizes security. Dendron's threat model and mitigations are documented and public.

🔐
API Key Exposure
BYOK callback pattern: Dendron never sees, holds, or transmits any API key. Your backend manages all key operations.
Eliminated by Architecture
⛓️
Supply Chain Attack
SHA-512 integrity hashes on all dependencies. <30 total production packages. CI fails on lockfile modification.
Implemented in CI
💉
XSS via Smart Card Content
All LLM response content is sanitized before rendering. Zero innerHTML on user/LLM data. DOM API (createElement/textContent) only.
Enforced in Card Renderer
🛡️
Host Page CSS Interference
Closed Shadow DOM encapsulation. No global styles. All Dendron CSS is scoped and inlined — invisible to the host page.
Enforced by Design
💾
IndexedDB Data Exfiltration
Same-origin policy (browser-enforced). Data is behavioral vectors, not PII. 7-day TTL with LRU eviction.
Browser-Enforced + SDK Policy
⚡
Main Thread Blocking
All computation in Web Worker. Main thread listeners do zero processing. <1ms budget enforced in CI.
Architecture + CI Enforced
