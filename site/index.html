How it works
Three minutes to intelligent

Dendron runs entirely in the browser. No backend to deploy, no database to manage, no user data to worry about.

1

Visitor browses your site

Dendron tracks scroll depth, reading time, clicks, and cursor patterns inside a Web Worker. Zero main-thread impact.

2

Intent score crosses threshold

The Context Engine scores engagement (0-100) across three dimensions. When it crosses your threshold, it fires.

3

Smart Card appears

Dendron calls your onQuery callback with behavioral context. Your backend asks your LLM. Dendron renders the response.

4

Visitor converts

Pricing cards when they're on pricing. Feature cards when they're exploring. The right message at the right moment.

🔒
Zero liability by design. Dendron never sees your API keys (BYOK callback). Never stores user data on any server. Never makes network requests. The only egress is your own onQuery callback.
Integration Guide
Add Dendron to your site

Three steps. Works with any framework. Under 5 minutes.

Install the SDK

Choose npm or CDN. That's the only dependency.

npm
npm install dendron-sdk
CDN (script tag)
<script src="https://unpkg.com/dendron-sdk@1.0.1/dist/dendron.min.js"></script>
💡
The npm package is 13KB gzipped with zero production dependencies. The optional micro-embeddings module (Transformers.js) is lazy-loaded only when needed.

Initialize Dendron on your page

Pick your framework. The only required parameter is onQuery — a callback that routes to your backend.

// app/layout.tsx (or any root component) 'use client'; import { useEffect } from 'react'; import { Dendron } from 'dendron-sdk'; export default function RootLayout({ children }) { useEffect(() => { Dendron.init({ onQuery: async (payload) => { const res = await fetch('/api/dendron', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(payload), }); return res.json(); }, systemContext: 'Your product description here', }); return () => Dendron.destroy(); }, []); return <>{children}</>; }
<!-- App.vue --> <script setup> import { onMounted, onUnmounted } from 'vue' import { Dendron } from 'dendron-sdk' onMounted(() => { Dendron.init({ onQuery: async (payload) => { const { data } = await $fetch('/api/dendron', { method: 'POST', body: payload, }) return data }, systemContext: 'Your product description here', }) }) onUnmounted(() => Dendron.destroy()) </script>

Section auto-discovery. Dendron automatically finds <section id="...">, <article>, and [data-dendron-section] elements. For best results, add data-dendron-section="pricing" to your key sections.

Create your backend proxy

Dendron calls your onQuery with behavioral context. Your backend sends it to your LLM and returns the Smart Card JSON. Dendron never sees your API key.

// pages/api/dendron.ts import OpenAI from 'openai'; import type { NextApiRequest, NextApiResponse } from 'next'; const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY }); export default async function handler(req: NextApiRequest, res: NextApiResponse) { const completion = await client.chat.completions.create({ model: 'gpt-4o-mini', messages: [{ role: 'user', content: req.body.prompt }], response_format: { type: 'json_object' }, max_tokens: 400, }); const card = JSON.parse(completion.choices[0].message.content ?? '{}'); res.json(card); }
// server.js import express from 'express'; import OpenAI from 'openai'; const app = express(); const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY }); app.use(express.json()); app.post('/api/dendron', async (req, res) => { const completion = await client.chat.completions.create({ model: 'gpt-4o-mini', messages: [{ role: 'user', content: req.body.prompt }], response_format: { type: 'json_object' }, }); res.json(JSON.parse(completion.choices[0].message.content)); }); app.listen(3001);
# app.py from flask import Flask, request, jsonify from openai import OpenAI import json app = Flask(__name__) client = OpenAI() @app.post('/api/dendron') def dendron_proxy(): payload = request.get_json() completion = client.chat.completions.create( model="gpt-4o-mini", messages=[{"role": "user", "content": payload["prompt"]}], response_format={"type": "json_object"}, ) card = json.loads(completion.choices[0].message.content) return jsonify(card)
🎯
Works with any LLM. Swap gpt-4o-mini for Claude, Groq, Mistral, Ollama, or any provider. Dendron doesn't care what's behind your callback.

Features
Everything you need, nothing you don't

13KB of intelligence. No bloat.

⚡

Web Worker Architecture

All behavioral processing runs off the main thread. Your site stays fast. <1ms CPU budget per frame.

🎨

5 Smart Card Types

Greeting, Feature, Pricing, Engagement, Comparison. Each contextually triggered by visitor behavior.

🔒

Shadow DOM Isolation

Closed shadow root. Your CSS never leaks in. Dendron's CSS never leaks out. Works on any site.

🔑

BYOK Architecture

Bring Your Own Key. Dendron never sees, stores, or transmits API keys. Your backend, your rules.

🌐

Framework Agnostic

React, Vue, Next.js, Nuxt, Astro, WordPress, vanilla HTML. One API, works everywhere.

🤖

WebMCP Agent Ready

Optional plugin auto-registers your site's actions for agentic browsers. Future-proof your UX.
